# MDMA para M-VAVE FM-1

Firmware de performance com seis camadas, cenas por cidade e sequenciador de bateria. A versão oficial e base do desenvolvimento é **0.5.6-controls**.

**[Baixar a versão oficial em ZIP](https://github.com/mdmarinato/MDMA/raw/refs/tags/v0.5.6-controls/downloads/v0.5.6-controls/MDMA-0.5.6-controls.zip)**

Extraia o ZIP. O arquivo de firmware para o FM-1 é `mdma-0.5.6-controls.fwsc`.
